## Notas

- Cada apêndice em PDF é um documento autónomo, com paginação própria: capa sem número, índices em numeração romana (i, ii, …) e numeração árabe (1, 2, 3, …) a partir do primeiro capítulo.
- Cada apêndice inclui as suas próprias referências bibliográficas no final.
- Na base de dados (Apêndice F), os inquiridos estão identificados apenas por número (Inquirido 1 a 67).
- A análise estatística foi feita no R Commander 4.6.1 (nível de significância α = 0,05).
